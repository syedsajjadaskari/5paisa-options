# Remaining Rulebook Ambiguities

The original PDFs were read before this context was defined. The following remain conservative blockers:

- **PDS:** good-red body threshold, HPR wick ratio, small-support size/lookback, support-break close versus touch, and exact entry timing.
- **PDR:** which prior-day reversal high is authoritative when multiple peaks exist, proximity tolerance, and the 35/40-point stop choice.
- **ORB:** established-trend structure, inner-level lookback, trendline construction, and numerical body/wick thresholds.
- **IRF Method 2:** recent support/resistance definition and exact extension/reversal confirmation.
- **RF:** exact entry price and target remain open; RF is disabled in this replay.

A rule is not promoted to executable status merely because a deterministic proxy exists in the baseline implementation.
